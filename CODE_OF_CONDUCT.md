# Code of conduct

This small academic project welcomes respectful participation in issues, pull requests and reviews. Treat others with consideration, recognise different levels of experience and make space for questions.

Disagreement is welcome when it helps improve the work. Explain concerns with evidence, suggest useful alternatives and respond to criticism without personal attacks. Always critique an idea or change rather than the person proposing it.

Harassment, discrimination, threats and sharing another person's private information without permission are unacceptable.

## Raising concerns

Cristina Correa Segade (`CrisCorreaS`) maintains this fork. To request contact, open an issue in the [repository's issue tracker](https://github.com/CrisCorreaS/capstone_repo/issues).

Issues are public. For a sensitive concern, ask the maintainer for a private contact route without posting incident details or personal information. Wait for a suitable route before sharing those details.

The maintainer may moderate harmful content or restrict participation when necessary to protect constructive collaboration.
